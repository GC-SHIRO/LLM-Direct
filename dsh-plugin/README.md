# DSH 机器人工作台（本地模拟 / 远程观测与手动控制）

适配本机 DSH `0.2.2-rc.1`。在已有会话中打开右侧栏，点 **+ → 机器人工作台 / Robot Workbench**。顶部、左腕和右腕同时显示为一张拼接图，不裁掉任一视角。布局随侧栏宽高压缩，空间太小时可以滚动；右上角「中文 / EN」即时切换面板语言，并记住选择。可以查看双臂状态、选择手臂做 5 mm 点动、开合夹爪、回预设关节姿态或停止双臂。画面在打开、手动刷新和成功动作后更新；轮询默认只刷新状态，可在设置里选择同时刷新相机快照（不是视频流）。连接异常时保留的画面会标记，点动、夹爪及复位受状态检查限制，超时不会重发动作。

## 工作台设置

点击连接状态右侧的滑杆图标打开设置。可选择跟随系统／浅色／深色、位姿与关节读数的小数位数（0–2），以及状态轮询间隔（1、2.5、5 秒）。修改即时生效并仅保存在当前浏览器；「恢复默认」将这三项还原，不更改语言或机器人状态。按 Esc 或「完成」关闭设置。

## 连接另一台电脑

1. 在运行 LLM-Direct 的电脑上配置好 `LLM_DIRECT_TOKEN`。建议先用模拟器联调：`python -m llm_direct.server --mock --mode auto --transport http --host 0.0.0.0 --port 8765`。选取服务启动时打印的可达局域网地址；不要把 `0.0.0.0`、机器人控制器地址或 DSH 页面地址填入侧栏。防火墙仅对 DSH 宿主机放行该端口。不要把机器人服务暴露到公网；跨不可信网络请用 HTTPS 或加密隧道，普通 HTTP 会明文传输令牌。
2. 工作台设置 → 连接目标 → 远程。输入完整地址，例如 `http://192.168.1.50:8765/mcp`，令牌框填写服务端配置的令牌本身（不加 `Bearer `），点击「应用连接」。出现 HTTP 401 时重新输入正确的令牌并再次应用。连接由 DSH 宿主发起，因此这台机器必须能访问目标地址。
3. 远程默认只观测。请核对已应用的地址、模拟/实机和模式；若新界面收到不带目标地址的旧宿主响应，会报错而不显示模拟数据。此时完全退出并重启 DSH（含宿主），不能只刷新页面。连接失败不会自动回退。上次地址仅作为输入草稿；新面板默认在本地，令牌仅在本次面板内使用。
4. 需要手动操作时，在设置中勾选「启用远程手动控制（仅此面板）」。只有已应用地址、令牌有效且状态校验通过后才能勾选；换目标、状态过期或动作结果未知会自动关闭。支持单臂单轴 5 mm 点动、夹爪开合、单臂复位及双臂软件停止，不提供使能、清错或修改工作区。
5. 实机当前仍有两道现场前提：左右臂必须已使能（现在报 `DISABLED` 时任何动作都会被拒），且 `config.py` 里的 `workspace_mm` 还没配置，所以实机上的 X/Y/Z 点动会被服务端拒绝，夹爪和复位不受此限。`supervised` 模式下每次动作都要机器人在主机终端按 Enter 确认；无人值守时该动作不会执行。

## 重新安装或迁移

在项目根目录准备 Python 3.10+ 环境（Windows PowerShell，已安装 uv）：

```powershell
uv venv .venv
uv pip install --python .\.venv\Scripts\python.exe -r pyproject.toml
node dsh-plugin/build.mjs
```

复制到新位置后，安装前将 [cordis.patch.yml](<cordis.patch.yml>) 的 `projectDir` 改成新项目的绝对路径。默认使用项目 `.venv` 下的 Windows Python；需要其他解释器时可配置绝对路径 `python`。在 DSH **插件 → 添加插件** 中选择插件目录的绝对路径，安装并启用；已有安装可直接打开右栏，若侧栏没有更新，先刷新客户端，必要时重启 DSH 以重新加载本地模块。停用/移除插件会停止后端并关闭当前窗口中属于它的标签。

## 连接方式和验证

侧栏通过 DSH 自带认证的同源 `/api` 接口调用宿主端；本地模拟模式下，宿主按需启动现有 Python MCP 服务，固定使用 `--mock --mode auto --transport stdio`。不需要另开 HTTP 服务或为聊天单独配置 MCP，也不会连真机。模拟进程和状态由这个插件实例共享，不与聊天里另外配置的 MCP 共享。不会把操作按钮注册成聊天工具。模拟 MCP 调用仍沿用项目的本地日志。

```powershell
node dsh-plugin/smoke.mjs
node dsh-plugin/smoke-client.mjs
node dsh-plugin/smoke-layout.mjs
node dsh-plugin/smoke-remote.mjs
```

这些测试只连接测试夹具或本机模拟器，不对真实机械臂下发命令。软件停止不是硬件急停。
